## English

- Add custom live speech recognition for DashScope ASR and OpenAI Realtime standalone transcription. Supply a full WebSocket URL, recognition model and API key. The service must support the selected real-time audio protocol; file transcription or Chat Completions compatibility alone is insufficient. Choose Original for recognition only, or configure text translation separately.
- Add OpenAI-compatible text translation with its own address, model and API key, alongside Alibaba, DeepL and DeepLX. Recognition and text translation have separate settings and credentials. Protocol requirements and longer explanations appear in help tooltips; fields, errors and compact action buttons remain visible. Changing a custom service address requires credentials for that destination.
- Add Dock visibility controls in the macOS tray. Refine multilingual settings and Android immersive-mode guidance and recovery. Contain extreme repeated subtitle output to keep the overlay responsive.

Desktop: update in Settings → General or download the package for your platform. Windows portable ZIP and Linux `.deb` require a manual replacement or installation. Versions before v1.3.8 need a manual installation before in-app updates work. macOS keeps the fixed self-signed identity and is not Apple-notarized; choose `_aarch64.dmg` for Apple silicon or `_x64.dmg` for Intel. Windows packages are unsigned and may trigger SmartScreen; the portable build requires WebView2. Linux x86_64 remains a preview requiring PulseAudio or PipeWire-Pulse and Secret Service.

Android: download `mimi_1.5.7_android.apk` (Android 10 or later). The new custom speech and text service editors are desktop features. Android captures system playback only; applications that prohibit playback capture and DRM-protected audio cannot be captured. The signed 1.5.6 release can update in place; debug installations use a different signature and must be removed first, deleting their settings and saved credentials.

Verification covers the full Rust/frontend checks and signed macOS UI checks for independent settings, write-only fields, Original mode and inline validation. Real Alibaba endpoints passed a custom DashScope connection check and recognition of a fixed synthesized phrase, plus OpenAI-compatible text translation to Chinese and Japanese. OpenAI standalone transcription is covered by local WebSocket fixtures for setup, ordering, Clear, stop and bounded buffers; a real OpenAI transcription account was not tested. Windows/Linux provider sessions, Intel Mac runtime and physical Android behavior remain unverified. Production credentials remain in the OS secure store. Available languages and third-party compatibility depend on the selected services and models.

## 中文

- 新增自定义实时语音识别，支持 DashScope ASR 和 OpenAI Realtime 独立转写协议。填写完整 WebSocket 地址、识别模型和 API Key；服务必须支持所选实时音频协议，普通文件转写或仅兼容 Chat Completions 的接口无法直接接入。选择「原文」可只做识别，也可另行配置文字翻译。
- 新增 OpenAI 兼容文字翻译，单独填写地址、模型和 API Key，与阿里云、DeepL、DeepLX 一同提供。识别与文字翻译分别配置、分别保存凭据。协议要求和较长说明放在帮助 tooltip 中，字段、错误提示及紧凑操作按钮保持可见。更换自定义服务地址时需填写对应服务的凭据。
- macOS 托盘新增 Dock 显示控制。调整多语言设置，以及 Android 沉浸模式的说明和恢复操作；限制极端重复字幕，保持浮窗响应。

桌面端：通过「设置 → 通用」更新，或下载对应平台安装包。Windows 绿色版 ZIP 和 Linux `.deb` 需手动替换或安装；早于 v1.3.8 的版本需先手动安装一次，才能使用应用内更新。macOS 沿用固定自签名身份，未经 Apple 公证；Apple 芯片请选择 `_aarch64.dmg`，Intel 请选择 `_x64.dmg`。Windows 安装包未签名，可能触发 SmartScreen；绿色版需要 WebView2。Linux x86_64 仍为预览版，需要 PulseAudio 或 PipeWire-Pulse 及 Secret Service。

Android：下载 `mimi_1.5.7_android.apk`（Android 10 或更新版本）。本次自定义识别及翻译编辑器属于桌面功能。Android 仅采集系统播放声音，无法采集禁止播放捕获的应用及受 DRM 保护的音频。已签名的 1.5.6 正式版可直接覆盖更新；debug 安装签名不同，需先卸载，卸载会删除其设置和已保存的凭据。

验证覆盖完整 Rust、前端检查，以及签名 macOS 界面中的独立配置、只写凭据字段、原文模式和字段旁验证提示。真实阿里云接口已通过自定义 DashScope 连接检查及固定合成语音识别，也已通过 OpenAI 兼容接口翻译为中文和日文。OpenAI 独立转写通过本地 WebSocket 测试验证会话建立、顺序、清除、停止和有界缓冲，未使用真实 OpenAI 转写账号验证。Windows/Linux 服务会话、Intel Mac 运行及 Android 真机行为仍未验证。正式版凭据继续保存在系统安全存储中；可用语言和第三方兼容性取决于所选服务与模型。
