## English

### What's changed

- Add a separate Intel Mac installer: `mimi_1.4.4_x64.dmg`, for macOS 13 or later. Apple silicon users should continue using `mimi_1.4.4_aarch64.dmg`.
- Include Intel packages in the standard release process and add an architecture-specific in-app update channel. Each Mac package is checked against its architecture, signed source revision and stable signing identity before publication.
- Keep the existing subtitle, system-audio capture and default-off session export behavior unchanged.

### Installation and verification

Download the DMG matching your Mac. Existing Apple silicon and Windows installer users can update through Settings → General → Software Update. Windows portable users should download and replace the ZIP manually.

macOS packages use the existing fixed self-signed certificate and are not Apple-notarized. Normal Open Anyway, Screen & System Audio Recording, or Keychain approval may be required; older ad-hoc installations may need renewed permission. Windows packages remain unsigned by Authenticode and may show SmartScreen prompts.

Verification covers repository checks, Intel cross-compilation, both signed macOS packages, architecture/source/DMG checks, and CI release validation. Intel hardware installation, launch, real-provider audio capture and permission behavior remain unverified. No Intel hardware acceptance or end-to-end installed updater acceptance is claimed.

## 中文

### 本次改进

- 新增独立的 Intel Mac 安装包 `mimi_1.4.4_x64.dmg`，要求 macOS 13 或更新版本。Apple 芯片用户请继续使用 `mimi_1.4.4_aarch64.dmg`。
- 将 Intel 包纳入常规发布流程，并加入对应架构的应用内更新通道。发布前分别校验每个 Mac 包的架构、已签名的源码提交标记和稳定签名身份。
- 字幕、系统音频采集和默认关闭的会话导出行为保持不变。

### 安装与验证

请选择与 Mac 芯片匹配的 DMG。现有 Apple 芯片和 Windows 安装版用户可通过「设置 → 通用 → 软件更新」升级。Windows 绿色版用户请手动下载并替换 ZIP。

macOS 包沿用固定的自签名证书，未经 Apple 公证。可能需要正常的「仍要打开」、屏幕与系统音频录制或钥匙串授权；旧版 ad-hoc 安装可能需要重新授权。Windows 包仍未进行 Authenticode 签名，可能出现 SmartScreen 提示。

验证覆盖仓库完整检查、Intel 交叉编译、两种架构的 macOS 签名包、架构/源码/DMG 校验及 CI 发布验证。Intel 实机安装、启动、真实服务商音频采集和权限行为仍未验证；不宣称已完成 Intel 实机验收或安装后的完整自动更新验收。
