## English

- On Linux Wayland, Settings now shows commands for starting or stopping subtitles, toggling Immersive Mode, and cycling subtitle display. Assign these commands in your desktop's keyboard settings. The commands control the existing Mimi instance; AppImage instructions use its actual file path. X11 keeps its existing global shortcuts.
- Linux shortcut hints now reflect the active display session. This release also carries the same signed Android app and desktop packages under version 1.5.3; Android has no new shortcut feature.

Desktop: update through Settings → General or download the package for your platform. Windows portable ZIP and Linux `.deb` users should replace/install the package manually. Versions before v1.3.8 require a manual installation before in-app updates become available. macOS packages retain the fixed self-signed identity and are not Apple-notarized. Choose `_aarch64.dmg` for Apple silicon or `_x64.dmg` for Intel. Windows packages are unsigned and may trigger SmartScreen; portable builds require WebView2. Linux x86_64 remains a preview requiring PulseAudio or PipeWire-Pulse and Secret Service. Wayland window placement and keyboard binding depend on the desktop environment.

Android: download `mimi_1.5.3_android.apk` below. Requires Android 10 or later and credentials for a supported translation service. It captures system playback only; apps that prohibit playback capture and DRM-protected audio cannot be captured. The signed 1.5.2 release can be updated in place. A debug installation uses a different signature and must be removed first, which deletes its settings and saved credentials.

Release checks cover Rust and frontend tests, installed Linux `.deb` and AppImage command forwarding under Xvfb, package and updater signature checks, Android unit tests and lint, APK version and signing identity, and Windows package smoke tests. An isolated Ubuntu 22.04 ARM64 VM also passed frontend and command actions under Weston Wayland; its headless compositor has no physical keyboard seat. Desktop-specific Wayland key binding and focus, physical Linux/Windows/Android devices, Intel Mac capture, and live sessions for every provider remain unverified.

## 中文

- Linux Wayland 下，设置页现在提供启动或停止字幕、切换沉浸模式和轮换字幕显示的命令。可在桌面环境的键盘设置中自行绑定；命令会控制已有的 Mimi 实例，AppImage 说明使用实际文件路径。X11 继续使用原有全局快捷键。
- Linux 快捷键提示现在会按当前显示会话呈现。本次也以 1.5.3 版本提供同一签名身份的 Android 应用和桌面安装包；Android 没有新增快捷键功能。

桌面端：通过“设置 → 通用”更新，或下载对应平台安装包。Windows 绿色版 ZIP 和 Linux `.deb` 用户需手动替换或安装；早于 v1.3.8 的版本需先手动安装一次才能使用应用内更新。macOS 沿用固定自签名身份，未经 Apple 公证；Apple 芯片请选择 `_aarch64.dmg`，Intel 请选择 `_x64.dmg`。Windows 安装包未签名，可能触发 SmartScreen；绿色版需要 WebView2。Linux x86_64 仍为预览版，需要 PulseAudio 或 PipeWire-Pulse 及 Secret Service。Wayland 窗口位置和按键绑定取决于桌面环境。

Android：下载下方的 `mimi_1.5.3_android.apk`，需要 Android 10 或更新版本，以及受支持翻译服务的凭证。仅采集系统播放声音，无法采集禁止播放捕获的应用和受 DRM 保护的音频。已签名的 1.5.2 正式版可直接覆盖更新；debug 测试版签名不同，需先卸载，卸载会删除其设置和已保存的凭证。

发布检查覆盖 Rust 和前端测试、Xvfb 下已安装 Linux `.deb` 与 AppImage 的命令转交、安装包及更新签名、Android 单元测试与 lint、APK 版本与签名身份，以及 Windows 安装包冒烟。隔离的 Ubuntu 22.04 ARM64 虚拟机还在 Weston Wayland 下通过了前端渲染和命令动作；该无界面合成器没有实体键盘席位。各 Wayland 桌面的按键绑定与焦点、Linux／Windows／Android 实体设备、Intel Mac 音频采集及所有服务商的真实会话仍未验证。
