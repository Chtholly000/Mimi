## English

- Choose translation only, original + translation, or original only in Settings, the floating controls, or the tray. Switch views without clearing subtitles or interrupting translation. Cycle through the views with Command+Shift+B on macOS or Ctrl+Shift+B on Windows / Linux X11.
- Use consistent Mimi-styled dropdowns throughout the app, with keyboard navigation, light/dark appearance, and menus that stay inside the window. Improve settings spacing and hover feedback.
- Close the macOS floating control panel by clicking outside it.
- Keep timestamps clear of right-aligned subtitles and keep the latest line visible when narrowing the subtitle window.
- Preserve the downloaded update and its install/restart action when changing the interface language.

Update through Settings → General, or download the package for your platform. Windows portable ZIP and Linux `.deb` users should replace/install the newer package manually. Versions before v1.3.8 require a manual installation before in-app updates become available. This is the desktop release; Android uses its separate `android-v1.5.1` release.

macOS packages retain the fixed self-signed identity and are not Apple-notarized. Choose `_aarch64.dmg` for Apple silicon or `_x64.dmg` for Intel. Windows packages are unsigned and may trigger SmartScreen; portable builds require WebView2. Linux x86_64 remains a preview requiring PulseAudio or PipeWire-Pulse and Secret Service; Wayland window behavior and shortcuts depend on the compositor.

Validation includes automated Rust/frontend checks and native macOS development-app checks for display switching, dropdown behavior, outside-click dismissal, and language changes across downloaded/installed synthetic updater states. The demonstration uses synthetic subtitles, not a live provider session. Full native long-history resize verification, Intel hardware capture, and physical Windows/Linux acceptance of this version remain unverified.

## 中文

- 可在设置、浮窗控制面板和托盘中选择“仅译文”“原文 + 译文”或“仅原文”。切换显示不会清空字幕或中断翻译；macOS 使用 Command+Shift+B，Windows / Linux X11 使用 Ctrl+Shift+B 循环切换。
- 应用内下拉统一为 Mimi 风格，支持键盘操作、深浅主题和窗口边缘避让，同时改善设置页间距与悬停反馈。
- macOS 浮窗控制面板支持点击外部收起。
- 修复右对齐字幕遮挡时间戳，以及缩窄字幕窗口后最新一句不可见的问题。
- 切换界面语言后保留已下载更新及其安装、重启入口。

可通过“设置 → 通用”更新，或下载对应平台的安装包。Windows 绿色版 ZIP 和 Linux `.deb` 用户请手动替换或安装新版；早于 v1.3.8 的版本需先手动安装一次才能使用应用内更新。本次为桌面版发布，Android 仍使用独立的 `android-v1.5.1` 版本。

macOS 沿用固定自签名身份，未经 Apple 公证；Apple 芯片请选择 `_aarch64.dmg`，Intel 请选择 `_x64.dmg`。Windows 安装包未签名，可能触发 SmartScreen；绿色版需要 WebView2。Linux x86_64 仍为预览版，需要 PulseAudio 或 PipeWire-Pulse 及 Secret Service；Wayland 窗口行为和快捷键取决于桌面环境。

验证包括 Rust／前端自动化检查，以及 macOS 原生开发版中的字幕显示切换、下拉操作、点击外部收起、合成更新下载／安装后跨语言切换。演示使用合成字幕，并非真实服务商会话。完整的原生长字幕缩放、Intel 实机采集，以及本版 Windows／Linux 实体设备验收仍待验证。
