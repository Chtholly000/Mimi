## English

- Android and desktop packages now ship together on this release page. Future `v*` releases wait for the signed Android APK and all desktop packages before publication, with one shared checksum list.
- Android 1.5.2 keeps the established release signing identity and increases the version code, allowing an in-place update from the signed Android 1.5.1 APK. This update changes release packaging; it does not add desktop-only subtitle controls to Android.
- Includes the desktop v1.5.1 subtitle display choices, Mimi-styled dropdowns, spacing improvements, outside-click dismissal, subtitle layout fixes, and preservation of downloaded updates when switching interface language.

Desktop: update through Settings → General or download the package for your platform. Windows portable ZIP and Linux `.deb` users should replace/install the package manually. Versions before v1.3.8 require a manual installation before in-app updates become available. macOS packages retain the fixed self-signed identity and are not Apple-notarized. Choose `_aarch64.dmg` for Apple silicon or `_x64.dmg` for Intel. Windows packages are unsigned and may trigger SmartScreen; portable builds require WebView2. Linux x86_64 remains a preview requiring PulseAudio or PipeWire-Pulse and Secret Service; Wayland behavior depends on the compositor.

Android: download `mimi_1.5.2_android.apk` below. Requires Android 10 or later and credentials for a supported translation service. Captures system playback only; apps that prohibit playback capture and DRM-protected audio cannot be captured. A debug installation uses a different signature and must be uninstalled first, which removes its settings and saved credentials. Users of the signed Android 1.5.1 release can install this APK over it.

The original native Android port was contributed by @yebuwudong in [#37](https://github.com/yuxino/mimi/pull/37).

Release gates cover Rust/frontend checks, desktop package verification, Android unit tests and lint, compiled APK version/debuggability checks, and the pinned Android signing certificate. Desktop interaction evidence comes from the v1.5.1 native macOS development app using synthetic subtitles. Physical Android/Windows/Linux acceptance, Intel capture, and all-provider live Android validation remain unverified.

## 中文

- Android 与桌面端安装包现在统一放在此发布页。后续 `v*` 版本会等待已签名 APK 和全部桌面安装包完成后一起发布，共用一份校验和清单。
- Android 1.5.2 沿用原正式签名并递增版本代码，可直接覆盖安装已签名的 Android 1.5.1。本次调整发布方式，不代表 Android 新增了桌面端专属字幕控制功能。
- 包含桌面端 v1.5.1 的字幕显示选项、Mimi 风格下拉、间距改善、点击外部收起、字幕布局修复，以及切换界面语言后保留已下载更新的修复。

桌面端：通过“设置 → 通用”更新，或下载对应平台安装包。Windows 绿色版 ZIP 和 Linux `.deb` 用户请手动替换或安装；早于 v1.3.8 的版本需先手动安装一次才能使用应用内更新。macOS 沿用固定自签名身份，未经 Apple 公证；Apple 芯片请选择 `_aarch64.dmg`，Intel 请选择 `_x64.dmg`。Windows 安装包未签名，可能触发 SmartScreen；绿色版需要 WebView2。Linux x86_64 仍为预览版，需要 PulseAudio 或 PipeWire-Pulse 及 Secret Service；Wayland 行为取决于桌面环境。

Android：下载下方的 `mimi_1.5.2_android.apk`，需要 Android 10 或更新版本，以及受支持翻译服务的凭证。仅采集系统播放声音，无法采集禁止播放捕获的应用和受 DRM 保护的音频。debug 测试版签名不同，需先卸载，卸载会删除其设置和已保存的凭证；已签名的 Android 1.5.1 正式版可直接覆盖安装。

原生 Android 版本最初由 @yebuwudong 在 [#37](https://github.com/yuxino/mimi/pull/37) 贡献。

发布检查包含 Rust／前端检查、桌面安装包校验、Android 单元测试与 lint、编译后 APK 版本及调试属性检查，以及固定 Android 签名证书校验。桌面交互证据来自使用合成字幕的 v1.5.1 原生 macOS 开发版。Android／Windows／Linux 实体设备验收、Intel 采集，以及 Android 全部服务商的真实会话验证仍待完成。
