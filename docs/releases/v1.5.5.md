## English

- Desktop subtitle color can now be chosen from five presets or entered as a custom HEX color in Settings. Thanks to @inhome for [#53](https://github.com/yuxino/mimi/pull/53) and [#54](https://github.com/yuxino/mimi/pull/54).
- Alibaba Cloud low-latency subtitles now pair confirmed originals and translations by utterance identity, including saved history and exports. Live bilingual previews only stack text from the same utterance. Thanks to @LLLin000 for [#63](https://github.com/yuxino/mimi/pull/63) and [#65](https://github.com/yuxino/mimi/pull/65).
- Android subtitles now start in a compact card. Tap it to open a reading panel; Immersive Mode shows text without the card and provides a movable exit control. Landscape layouts leave more room for the underlying video. @yuxino added these changes in [#60](https://github.com/yuxino/mimi/pull/60).
- The desktop **Save & export** page now explains what each switch saves and when it takes effect. Empty records no longer show zero summaries, a disabled search field, or export actions. The redundant tip at the bottom of the Settings sidebar has been removed.
- The subtitle display selector in the tray panel now stays beside its label instead of dropping below it.
- When Baidu rejects a realtime translation session during setup, Mimi now keeps the provider's numeric rejection code in its content-free error message. This helps diagnose the rejection; it does not establish that every reported Baidu connection failure has been fixed. [Issue #62](https://github.com/yuxino/mimi/issues/62) remains open pending a reproducible failure with a code.
- The signed Android APK is included as version 1.5.5 with the existing release identity.

Desktop: update in Settings → General or download the package for your platform. Windows portable ZIP and Linux `.deb` users must replace or install the package manually. Versions before v1.3.8 need a manual installation before in-app updates work. macOS packages keep the fixed self-signed identity and are not Apple-notarized; choose `_aarch64.dmg` for Apple silicon or `_x64.dmg` for Intel. Windows packages are unsigned and may trigger SmartScreen; the portable build requires WebView2. Linux x86_64 remains a preview requiring PulseAudio or PipeWire-Pulse and Secret Service.

Android: download `mimi_1.5.5_android.apk`. It requires Android 10 or later and credentials for a supported translation service. It captures system playback only; apps that prohibit playback capture and DRM-protected audio cannot be captured. The signed 1.5.4 release can be updated in place. A debug installation has a different signature and must be removed first, which deletes its settings and saved credentials.

Automated Rust, frontend, packaging, updater-signature, and Android checks are part of release verification. The Alibaba Cloud confirmed-pair fix was verified in a real Windows low-latency session; the follow-up preview pairing has automated coverage but no live-session verification yet. Android overlay states were checked in an emulator, but physical-device touch behavior remains unverified. The Baidu handshake was accepted in a limited macOS check, but a full live translation session on the reporter's Windows machine has not been reproduced. Physical-device acceptance for every platform and provider remains unverified unless noted in the release checks.

**Full changelog:** [v1.5.4...v1.5.5](https://github.com/yuxino/mimi/compare/v1.5.4...v1.5.5)

## 中文

- 桌面端现在可在设置中选择五种字幕预设颜色，或输入自定义 HEX 色值。感谢 @inhome 提交 [#53](https://github.com/yuxino/mimi/pull/53) 和 [#54](https://github.com/yuxino/mimi/pull/54)。
- 阿里云低延迟字幕现在按同一句的身份配对确认后的原文与译文，保存的历史和导出内容也会正确配对；双语实时预览只叠放同一句的文字。感谢 @LLLin000 提交 [#63](https://github.com/yuxino/mimi/pull/63) 和 [#65](https://github.com/yuxino/mimi/pull/65)。
- Android 字幕默认显示为紧凑卡片，点击可展开阅读面板；沉浸模式只显示字幕文字，并提供可移动的退出按钮。横屏布局为底下的视频留出更多空间。@yuxino 在 [#60](https://github.com/yuxino/mimi/pull/60) 加入了这些改动。
- 桌面端「保存与导出」页面现在直接说明每个开关保存什么、何时生效。没有内容时不再显示零计数、不可用的搜索框和导出按钮；设置侧栏底部重复的「使用提示」也已移除。
- 托盘中的「字幕显示」选择框现在会与标题保持在同一行，不再掉到下方。
- 百度实时翻译若在建立会话时拒绝请求，Mimi 现在会在不包含内容的错误信息中保留服务端数字错误码，方便定位原因。这不代表所有百度连接问题已修复；[#62](https://github.com/yuxino/mimi/issues/62) 会保持开启，等待带错误码的可复现情况。
- 本次同时提供沿用原正式签名身份的 Android 1.5.5 APK。

桌面端：通过「设置 → 通用」更新，或下载对应平台安装包。Windows 绿色版 ZIP 和 Linux `.deb` 用户需手动替换或安装；早于 v1.3.8 的版本需先手动安装一次，才能使用应用内更新。macOS 沿用固定自签名身份，未经 Apple 公证；Apple 芯片请选择 `_aarch64.dmg`，Intel 请选择 `_x64.dmg`。Windows 安装包未签名，可能触发 SmartScreen；绿色版需要 WebView2。Linux x86_64 仍为预览版，需要 PulseAudio 或 PipeWire-Pulse 及 Secret Service。

Android：下载 `mimi_1.5.5_android.apk`，需要 Android 10 或更新版本及受支持翻译服务的凭证。仅采集系统播放声音，无法采集禁止播放捕获的应用和受 DRM 保护的音频。已签名的 1.5.4 正式版可直接覆盖更新；debug 测试版签名不同，需先卸载，卸载会删除其设置和已保存的凭证。

发布验证包含 Rust、前端、安装包、更新签名及 Android 自动检查。阿里云确认句子配对的修复已在 Windows 低延迟真实会话中验证；后续的实时预览配对有自动测试，但尚未经过真实会话验证。Android 浮窗状态已在模拟器中检查，但实体设备上的触摸行为仍待验证。百度握手曾在 macOS 上的有限测试中成功，但尚未在反馈者的 Windows 电脑上复现并完成真实翻译会话。除发布检查明确列出的部分外，各平台及服务商的实体设备验收仍未覆盖。
