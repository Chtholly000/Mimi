## English

- Live subtitles now keep complete source/translation previews together while the next request runs. Alibaba sentence identities distinguish repeated lyrics from duplicate events and keep a late confirmation from replacing a newer sentence. Long subtitles can be expanded for reading, with **Return to live**, Home/End navigation and preserved reading position across confirmations, resizing and display-mode changes. Subtitle motion, sound-light styles and subtle sentence dividers have separate controls; dividers are off by default.
- Alibaba's default text-translation route now uses Qwen-MT Lite. Request pacing accounts for text length, confirmed sentences take priority, and fast speech no longer repeatedly cancels an already started preview. Rate-limit recovery keeps listening with a visible status instead of silently ending the session. Previous captions are no longer submitted as automatic translation examples. These changes reduce redundant work; they do not guarantee a fixed latency or prevent provider quotas.
- Service details now group credentials, connection checks and language choices. Larger language menus support searching by name or code. The default Alibaba translation route offers 24 explicit source languages plus automatic detection, and 31 targets plus Original; Original supports all 30 Audio3 source languages. Simplified and Traditional Chinese are distinct targets. Other routes retain their own supported choices. Official DeepL text translation and a separate custom service compatible with the DeepLX API can use Alibaba speech recognition; DeepL requires its own API key.
- **System**, **Direct** and **Custom** proxy choices apply to both recognition and translation, including connection checks. Custom HTTP, SOCKS5 and SOCKS5h proxies are supported without proxy authentication. Change routing after stopping the session. PAC scripts and authenticated proxy URLs are not supported.
- Windows can follow an audible system output or use a selected output device, including communication-device routing. The overlay shows actual capture status; macOS identifies the current system output without presenting it as the device bound to capture. The compact control menu, collapsed controls, first-click actions, hover feedback and error/retry states have been refined. macOS adds a Dock visibility setting and **Settings…** / Quit menu actions; normal exit finalizes active local session files before closing.
- Settings now have a visible first-use guide and a dedicated **Diagnostics** page with copyable, content-free status, timings, counts and recent failure categories. Connection checks verify service authorization and keep their result distinct from an active-session error. Subtitle updates continue while credential loading is delayed; Linux distinguishes unavailable secure storage from rejected access, and unsaved credential drafts survive recovery. Clearing subtitles cuts queued content without reconnecting, and later sentences continue. Saved-history export and pending deletion preserve the current view; Linux AppImage launcher permissions are corrected.
- Android gains first-use and permission guidance, links to official service help, real capture-PCM health reporting and copyable safe diagnostics. The signed APK remains part of this same release. Contributors can also use a documented, read-only credential file in the explicitly enabled macOS development bundle; production builds continue to use OS credential storage.

Desktop: update in Settings → General or download the package for your platform. Windows portable ZIP and Linux `.deb` users must replace or install the package manually. Versions before v1.3.8 need a manual installation before in-app updates work. macOS keeps the fixed self-signed identity and is not Apple-notarized; choose `_aarch64.dmg` for Apple silicon or `_x64.dmg` for Intel. Windows packages are unsigned and may trigger SmartScreen; the portable build requires WebView2. Linux x86_64 remains a preview requiring PulseAudio or PipeWire-Pulse and Secret Service.

Android: download `mimi_1.5.6_android.apk`. It requires Android 10 or later and credentials for a supported service. It captures system playback only; applications that prohibit playback capture and DRM-protected audio cannot be captured. The signed 1.5.5 release can be updated in place. A debug installation has a different signature and must be removed first, which deletes its settings and saved credentials.

Verification covers automated Rust/frontend checks and representative signed-macOS Alibaba sessions. Windows x64/ARM64 startup and Linux `.deb`/AppImage startup were checked in hosted UI-only environments for the preceding clear/control baseline; those runs do not prove real audio or provider behavior for every platform or the later sentence-identity fix. Request timings are not end-to-end subtitle latency. Physical Android, Intel Mac, Windows/Linux provider sessions, every language and physical fullscreen/global-shortcut behavior remain unverified unless explicitly recorded in the release checks. Local/system translation is deferred. Clear does not promise a cloud-audio cut at an exact wall-clock instant: the current pipeline does not align provider word timings with the Clear action.

## 中文

- 实时字幕会在下一次请求期间保留完整的原文与译文对。阿里云句子身份用于区分重复歌词和重复事件，较晚确认的旧句也不会覆盖新句。长字幕可展开阅读，通过「回到实时」及 Home/End 导航返回，并在确认、调整窗口及切换显示方式时保留读位。字幕动效、声音状态灯样式和细分句线分别可设，分句线默认关闭。
- 阿里云默认文字翻译路线改用 Qwen-MT Lite。请求节奏考虑正文长度，确认句子优先，快语速不再反复取消已经开始的预览。限流恢复期间保持采音并显示状态，不再悄悄结束会话；上一句字幕也不会自动作为翻译示例发送。这些改动减少重复请求，不保证固定延迟，也不能绕过服务商额度。
- 服务详情把凭据、连接检查和语言选择放在一起，大列表可按语言名或代码搜索。阿里默认翻译路线可选 24 种明确识别语言及自动识别、31 种目标及原文；原文模式支持 Audio3 的全部 30 种源语言。简体、繁体中文是不同目标，其他路线保留各自支持范围。新增 DeepL 官方文字翻译及独立的 DeepLX 接口兼容自定义服务，均可沿用阿里云识别；DeepL 需要单独的 API Key。
- 「系统」「直连」「自定义」代理同时应用于识别、翻译和连接检查。自定义支持无需鉴权的 HTTP、SOCKS5 及 SOCKS5h 代理，需停止会话后修改。暂不支持 PAC 脚本或带代理账户的地址。
- Windows 可跟随正在发声的系统输出，或指定输出设备，包括通信设备路由。浮窗显示实际采音状态；macOS 显示当前系统输出名称，不把它冒称为采集绑定设备。紧凑控制菜单、收起控件、首次点击、悬停反馈及错误重试状态均作了调整。macOS 新增 Dock 显示开关及「设置…」/退出菜单；正常退出会先完成当前本地会话文件。
- 设置中可直接找到新手指引和独立「诊断」页，复制不含正文的状态、耗时、计数和近期错误类别。连接检查验证服务授权，结果与当前会话错误分别显示。凭据加载延迟时字幕更新仍会继续；Linux 区分凭据服务不可用和访问被拒绝，恢复后保留未保存的凭据输入。清除字幕会隔离排队内容，不重连，后续新句仍能继续。历史导出和等待删除时保留当前视图，并修复 Linux AppImage 启动器权限。
- Android 新增首次使用及权限指引、官方服务帮助链接、基于真实 PCM 的采音健康状态和安全诊断复制。签名 APK 仍与桌面端放在同一个版本中。贡献者也可在明确启用的 macOS 开发版使用文档说明的只读凭据文件，正式构建继续使用系统凭据存储。

桌面端：通过「设置 → 通用」更新，或下载对应平台安装包。Windows 绿色版 ZIP 和 Linux `.deb` 用户需手动替换或安装；早于 v1.3.8 的版本需先手动安装一次，才能使用应用内更新。macOS 沿用固定自签名身份，未经 Apple 公证；Apple 芯片请选择 `_aarch64.dmg`，Intel 请选择 `_x64.dmg`。Windows 安装包未签名，可能触发 SmartScreen；绿色版需要 WebView2。Linux x86_64 仍为预览版，需要 PulseAudio 或 PipeWire-Pulse 及 Secret Service。

Android：下载 `mimi_1.5.6_android.apk`，需要 Android 10 或更新版本及受支持服务的凭据。仅采集系统播放声音，无法采集禁止播放捕获的应用和受 DRM 保护的音频。已签名的 1.5.5 正式版可直接覆盖更新；debug 测试版签名不同，需先卸载，卸载会删除其设置和已保存的凭据。

验证覆盖 Rust、前端自动检查及签名 macOS 上代表性的阿里云真实会话。此前清除与控制基线已在托管 UI-only 环境验证 Windows x64/ARM64 启动及 Linux `.deb`/AppImage 启动；这些结果不代表各平台真实采音、全部服务或后续句子身份修复已完成验收。请求耗时不等于声音到字幕的全链路时延。除发布检查明确记载的部分外，Android 实体设备、Intel Mac、Windows/Linux 真实服务会话、全部语言及物理全屏/全局快捷键仍未验证。本机/系统翻译继续暂缓。清除不承诺在精确时刻截断云端音频：当前管线没有把服务端词级时间与清除操作对齐。
