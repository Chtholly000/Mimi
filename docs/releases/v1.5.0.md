## English

- Add Linux x86_64 preview support with `.deb` and AppImage packages, built on Ubuntu 22.04.
- Capture system output through PulseAudio or PipeWire's `pipewire-pulse` service. Mimi connects only to the output monitor and never falls back to a microphone. Restart the session after changing output devices.
- Keep Linux API credentials in the desktop's Secret Service, such as GNOME Keyring. The keyring must be available and unlocked; there is no plaintext fallback. Audio recording and subtitle retention remain off by default.
- AppImage supports signed in-app updates. For `.deb`, Settings opens GitHub Releases to download and install the newer package.

Linux requires a working default output device and PulseAudio or `pipewire-pulse`. X11 is recommended; Wayland positioning, always-on-top, click-through, and global shortcuts depend on the compositor. Use Settings when a desktop has no tray host; minimize it to keep running, or close it to exit Mimi on Linux. Linux ARM64 packages are not included.

Verification covers automated Rust/frontend checks, generated-audio PulseAudio loopback, an isolated Secret Service round trip, package inspection, and credential-free Xvfb launches. Physical Linux hardware, live provider translation, and every Wayland compositor have not been verified.

Existing macOS and Windows installation requirements remain: macOS packages use the fixed self-signed identity and are not Apple-notarized; Windows packages are unsigned and may trigger SmartScreen. Choose `_aarch64.dmg` for Apple silicon or `_x64.dmg` for Intel. Intel hardware capture remains unverified. Windows portable ZIP builds update by manual replacement and require WebView2. Versions before v1.3.8 need a manual installation to enable in-app updates. See the README for bounded macOS permission recovery; do not delete credentials or certificates.

## 中文

- 新增 Linux x86_64 预览支持，提供以 Ubuntu 22.04 构建的 `.deb` 和 AppImage 安装包。
- 通过 PulseAudio 或 PipeWire 的 `pipewire-pulse` 服务采集系统输出。Mimi 只连接输出监听通道，不会回退到麦克风；切换输出设备后请重新开始会话。
- Linux API 凭证保存在桌面的 Secret Service 中，例如 GNOME Keyring。密钥环需可用且已解锁，不提供明文回退。音频录制和字幕保留仍默认关闭。
- AppImage 支持签名验证的应用内更新；`.deb` 的设置页面提供 GitHub Releases 入口，用于下载并安装新版软件包。

Linux 需要可用的默认输出设备，以及 PulseAudio 或 `pipewire-pulse`。建议使用 X11；Wayland 的窗口定位、置顶、点击穿透和全局快捷键取决于桌面环境。没有托盘图标时仍可使用设置窗口；最小化会继续运行，关闭设置窗口则退出 Mimi。暂不提供 Linux ARM64 安装包。

验证覆盖 Rust／前端自动化检查、合成音频的 PulseAudio 回环、独立 Secret Service 存取、安装包检查和无凭据的 Xvfb 启动。Linux 实体硬件、真实服务商翻译以及各类 Wayland 桌面尚未验证。

macOS 和 Windows 的安装要求保持不变：macOS 使用固定自签名身份，未经 Apple 公证；Windows 安装包未签名，可能触发 SmartScreen。Apple 芯片请选择 `_aarch64.dmg`，Intel 请选择 `_x64.dmg`，Intel 实机采集仍待验证。Windows 绿色版 ZIP 需手动替换更新，且需要 WebView2。早于 v1.3.8 的版本需先手动安装一次才能使用应用内更新。macOS 权限异常请参考 README 的有限恢复步骤，不要删除凭证或证书。
