## English

- Bilingual desktop subtitles now show the streaming translation below the original before a sentence pair is confirmed. The confirmed pair replaces the previews. Thanks to @LLLin000 for the fix in [#61](https://github.com/yuxino/mimi/pull/61), which addresses [#59](https://github.com/yuxino/mimi/issues/59).
- @yuxino added session history in Settings: browse saved sessions by day, search confirmed subtitles, play saved system audio when available, export, and delete a session. Keeping subtitles and recording system audio remain separate, off-by-default choices; enabled content is saved in private local files instead of retaining full transcripts or audio in memory.
- The signed Android APK is included at version 1.5.4 with the existing release identity. These desktop subtitle and session-history changes do not add Android features.

Desktop: update in Settings → General or download your platform's package. Windows portable ZIP and Linux `.deb` users should replace or install the package manually. Versions before v1.3.8 need a manual installation before in-app updates work. macOS packages keep the fixed self-signed identity and are not Apple-notarized; choose `_aarch64.dmg` for Apple silicon or `_x64.dmg` for Intel. Windows packages are unsigned and may trigger SmartScreen; the portable build requires WebView2. Linux x86_64 remains a preview requiring PulseAudio or PipeWire-Pulse and Secret Service.

Android: download `mimi_1.5.4_android.apk`. It requires Android 10 or later and credentials for a supported translation service. It captures system playback only; apps that prohibit playback capture and DRM-protected audio cannot be captured. The signed 1.5.3 release can be updated in place. A debug installation uses a different signature and must be removed first, which deletes its settings and saved credentials.

The contributor verified the bilingual preview with a real Alibaba Cloud low-latency session on Windows. Physical-device acceptance and live sessions for other providers remain unverified for this change.

**Full changelog:** [v1.5.3...v1.5.4](https://github.com/yuxino/mimi/compare/v1.5.3...v1.5.4)

## 中文

- 桌面端双语字幕现在会在句子确认前，将流式译文显示在原文下方；确认后的句子会接替预览。感谢 @LLLin000 在 [#61](https://github.com/yuxino/mimi/pull/61) 提交修复，解决了 [#59](https://github.com/yuxino/mimi/issues/59)。
- @yuxino 在设置页加入了会话历史：可按日期浏览已保存的会话、搜索确认后的字幕，在有录音时播放系统音频，并导出或删除会话。“保留字幕”和“录制系统音频”仍是彼此独立、默认关闭的选项；启用后内容写入本地私有文件，不在内存中保留完整字幕或音频。
- 本次同时提供沿用原正式签名身份的 Android 1.5.4 APK。上述桌面端字幕和会话历史改动不代表 Android 增加了对应功能。

桌面端：通过“设置 → 通用”更新，或下载对应平台安装包。Windows 绿色版 ZIP 和 Linux `.deb` 用户需手动替换或安装；早于 v1.3.8 的版本需先手动安装一次，才能使用应用内更新。macOS 沿用固定自签名身份，未经 Apple 公证；Apple 芯片请选择 `_aarch64.dmg`，Intel 请选择 `_x64.dmg`。Windows 安装包未签名，可能触发 SmartScreen；绿色版需要 WebView2。Linux x86_64 仍为预览版，需要 PulseAudio 或 PipeWire-Pulse 及 Secret Service。

Android：下载 `mimi_1.5.4_android.apk`，需要 Android 10 或更新版本及受支持翻译服务的凭证。仅采集系统播放声音，无法采集禁止播放捕获的应用和受 DRM 保护的音频。已签名的 1.5.3 正式版可直接覆盖更新；debug 测试版签名不同，需先卸载，卸载会删除其设置和已保存的凭证。

贡献者已在 Windows 上用阿里云低延迟真实会话验证双语预览。本次改动尚未在实体设备及其他服务商的真实会话中逐一验证。

**完整改动：**[v1.5.3...v1.5.4](https://github.com/yuxino/mimi/compare/v1.5.3...v1.5.4)
