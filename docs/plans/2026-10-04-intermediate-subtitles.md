# 显示中间字幕开关

默认开启，保留现有即时显示。设置页与托盘提供同一个偏好，可在运行中切换；
关闭后只投影确认行与确认历史，服务请求、final 通道、顺序、代次、录制及
导出保持原规则。停止时既有有界尾句收尾仍可显示，不能称为服务 final。
确认可能更晚；不宣称识别或翻译更准确。

共享核心的 displayPairFinal 随快照传到各输入轨道。完成的 previewPair
仍是预览，isStable 只表示前端可直接呈现，不能当作 final。缺字段的旧
displayPair 视为未确认；旧偏好默认显示中间字幕。确认行不添加额外等待。

只隐藏预览已经能解决可见替换问题，先不增加稳定等级，不减少预览 MT
请求。持续无停顿对白仍受服务确认边界限制。Gemini 的完整块是有界检查点，
并非服务保证的句子边界；关闭后出现间隔需要实测。

验证使用共享 Rust / JNI 合成契约、真实 OverlayWindow DOM 回归、既有
私有快照的成对离线回放，以及 canonical 签名开发版。相同事件在两个
显示设置下比较替换、首次出现、稳定阅读时间、final 到 DOM 和确认覆盖。
准确性沿用独立参考与原输出，本改动不改变输出，不能从稳定显示推断精度。
私有正文不进入诊断或 Git；公开记录只写数量、计时与限制。

桌面新增开关。Android 暂不新增原生设置，其共享快照暴露相同确认字段，
实际 JNI 契约验证这一边界；桌面测试不代表 Android UI 验收。
