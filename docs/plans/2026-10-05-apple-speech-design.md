# Apple 本地语音识别

## 范围

在符合条件的 Mac 上提供独立的 Apple Speech 识别渠道，复用 Mimi 的
系统声音／显式麦克风采集和独立文字翻译管线。语音识别在设备上运行，
翻译可选择已有的 Index 等 OpenAI 兼容服务；这不是 Apple 文字翻译集成。
与通用错误恢复及语言能力一起整合进产品主线。
原生验收使用稳定签名的 canonical dev。

## 原生边界

- 使用 macOS 26 的 `SpeechAnalyzer` / `SpeechTranscriber`，仅 Apple
  silicon 构建链接 Swift 静态库。最低应用部署版本仍为 macOS 13；所有新
  API 入口经过系统版本和 `SpeechTranscriber.isAvailable` 检查。
- Apple silicon 的 macOS 构建需要 Xcode 26+；缺少 SDK 时明确失败。
  Intel、Windows、Linux 编译不可用实现，不链接 Swift 或显示添加入口。
  用户安装后的应用不需要 Python、Xcode、WebSocket 桥或识别 API Key。
- 每个声音来源拥有独立原生 session、有界 PCM 和结果队列。取消、清空、
  重连以代次隔离迟到结果；草稿替换同一句，确认结果保留稳定身份。
  继续使用既有共享字幕核心及最终翻译策略，不增加另一个字幕 reducer。
- C ABI 只跨越数据、生命周期和净化后的状态；文本不进入普通日志，
  Swift 不拥有系统捕获或麦克风权限。沿用已有的采集授权和保存开关。

## 服务与语言

- 新增 `appleSpeech` profile，识别无凭据。独立文字翻译仍使用自己的
  私有凭据槽；不创建空识别密钥、不访问 legacy OS 凭据。
- 设置页读取系统支持的 locales，与 Mimi 现有语言枚举求交集。没有自动
  识别选项。每种语言固定一个明确 locale，安装状态改变不自动切换地区。
  资源准备目录保留系统支持语种；实际识别选项仅取系统支持、资源已准备、
  当前文字翻译路线兼容的交集。同一就绪快照供设置、托盘和浮窗控件使用。
- 添加入口仅在系统实际可用时展示；创建、选择和启动在后端再次校验。
  已保存但本机不可用的配置保留可编辑，不自动切换到云识别。
- 用户先在“语音资源”选择并准备语种，再明确点击“用此语言识别”，或在
  “识别语言”中选择。只有明确的准备动作可以请求下载资产。
  显示准备中、已就绪和可重试的失败，普通查询和开始识别
  不隐式下载。额外解释放在相邻帮助提示，状态和恢复动作常规字号可见。
- 使用 Apple 官方标志，与现有服务图标的尺寸、深浅主题及可访问标签一致。
  识别不显示地址、模型、Key 或网络代理；文字翻译保留独立设置与连接检查。

## 验证与交付

- 覆盖不可用平台、动态语言及地区选择、资源准备失败、无识别密钥、独立
  MT 槽、partial/final、清空／取消／收尾和队列上限；执行仓库完整检查。
- 复用公开合成英文样本，分别验证原生适配层和文字翻译，不把样本正确或
  请求耗时泛化为真人准确率和采音至显示的端到端延迟。
- 通过稳定签名的开发应用检验设置、系统音频捕获与浮窗。PR 逐项列出
  实际验证与剩余限制；不因独立桥接成功宣称完成原生应用验收。
- Apple 本地识别是 macOS 特有能力；Android 和其他桌面平台维持原有渠道。

## 语言就绪状态与切换

识别语言列表只提供本机当前可用的选择。系统支持但未准备资源的语言留在
“语音资源”目录；不放进设置、托盘或浮窗的实际识别选项。当前翻译路线
不支持的源语言同样不进入识别列表；“跳过翻译”按该路线重新计算交集。
下载成功后的能力广播让所有窗口同步增加就绪语言，普通查询和切换不下载。

能力查询失败或资源消失后，拒绝切换也必须发布刷新后的能力快照，移除
失效选项。保留原来的源语言偏好和当前会话；不将资源就绪集合接入通用
偏好归一化，不因资源状态变化自动改语言。旧偏好不在就绪集合时仍显示
本地化名称，但不作为可选项插回菜单；仅剩一个可用语种时仍允许明确切换。
没有就绪且兼容的语种时，设置页说明前往资源准备或调整翻译配置。

能力快照附带完整本机资源状态的版本号，与资源缓存同锁读取；只有资源
状态变化才更新，包括被翻译路线过滤的语种。资源面板观察版本变化后
重新查询本机状态；相同快照广播不反复查询，隐藏时不查询，迟到响应
不覆盖明确准备后的结果。自动刷新
使用面板内状态，不占用语言切换或资源准备操作的通知位置。

Apple 安全错误标签在语言切换、配置选择和会话操作共用同一文案映射。
缺资源指向“语音与翻译”的准备入口，系统不支持与翻译不兼容分别说明，
准备中提示等待。未知原生错误不直接显示，避免泄露正文或运行细节。

## 资源入口与下一步导引

资源区用一行常规字号说明“选语言 → 准备资源 → 用此语言识别 → 开始字幕”。
资源目录的选中项与实际识别语言仍是两个状态：查看或准备某种语言不保存
识别偏好、不选择配置，也不自动开始采音。模型地区、系统支持和下载条件
保留在相邻帮助提示，不用额外小字解释操作。

资源就绪后，只有正在使用的 Apple 配置、且该语言兼容当前文字翻译路线时，
才提供“用此语言识别”按钮。按钮显式保存识别语言，成功后提示可以开始字幕；
已是当前语言则直接显示这一状态。未使用的配置提示先点击“使用此配置”，
翻译路线不兼容则提示更换文字翻译服务或启用“跳过翻译”。按钮沿用设置的
会话锁和操作中状态，点击时再次核对当前配置与就绪能力，失败保留原选择。

Apple 的识别语言控件旁提供“语音资源”入口；缺资源、准备中或准备失败的
错误恢复动作使用“打开语音资源”。入口直接打开当前 Apple 配置的资源区，
不只停在服务列表；导航不自动下载、换配置或开始字幕。资源目录即使包含
尚未准备或不兼容当前翻译路线的语言，也不会把它们插回实际识别选项。
中、英、日同步提供步骤、状态、动作及恢复说明。
